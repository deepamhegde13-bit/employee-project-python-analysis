# 🐍 Employee Project Analysis using Python

## Project Overview

This project demonstrates how Python and Pandas can be used to solve real-world business analytics problems involving employee, project, and seniority datasets.

The notebook walks through a complete data analytics workflow including data cleaning, transformation, merging, business rule implementation, reporting, and exporting processed datasets.

---

## Business Problem

Organizations often receive employee and project data from multiple sources. Before meaningful reporting can be performed, the data must be cleaned, transformed, merged, and validated.

This project simulates that workflow using Python and Pandas.

## How to Run the Project

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy notebook
   ```

4. Open `employee_project_analysis.ipynb` from the repository root.
5. Ensure the input CSV files are available in the `Employee_Project_Analysis` folder.
6. Run the notebook cells sequentially, from top to bottom.
7. Check the generated CSV files and project outputs.

Run the notebook from the repository root so that relative file paths resolve correctly.

## Data Processing Workflow

The notebook demonstrates the following steps:

1. Load and inspect employee, project and seniority datasets.
2. Handle missing values and clean the data.
3. Transform and standardise relevant columns.
4. Merge datasets for combined analysis.
5. Apply business rules to project status, bonuses and employee seniority.
6. Generate the final dataset and export processed CSV files.

## Output Files

The notebook produces processed datasets, including `UpdatedEmployee.csv`, `UpdatedProject.csv` and `Final.csv`.

The original input datasets are `Employee.csv`, `Project.csv` and `Seniority.csv`. The updated files are generated during processing and may be overwritten when the notebook is rerun.
